Based on [@UnsignedArduino's code](https://github.com/UnsignedArduino/Audio-To-MakeCode-Arcade), the website allows you to convert WAV audio to MakeCode Arcade code to "import" audio. Like any audio import tool for MakeCode Arcade, it attempts to re-construct the original audio by playing multiple sine waves many times a second, and will not sound good.
