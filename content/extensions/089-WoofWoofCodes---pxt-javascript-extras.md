This extension adds a lot of random little blocks normally hidden to JavaScript, all in one extension, such as some extra image manipulation, customizing built-in UIs (lives, info HUD), system menu blocks, sprite APIs, and more! It adds a `Buffer` and `Extras` category under the advanced category drawer, and many more blocks scattered throughout the categories. It's recommended to read the [source code](https://github.com/WoofWoofCodes/pxt-javascript-extras/blob/master/extras.ts) of the extension to see what you get.
