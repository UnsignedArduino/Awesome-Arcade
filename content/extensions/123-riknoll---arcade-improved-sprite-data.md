This extension expands upon the built-in sprite data extension by providing more types including tilemap locations, functions, and the array versions of the base types that can be stored not only on sprites but also the tilemap locations on the current tilemap and an "object", replacing the arcade-block-objects extension. Unlike the built-in sprite data extension, it does not add blocks to the `Sprites` category, it adds them to a `SpriteData` category in the toolbox.
