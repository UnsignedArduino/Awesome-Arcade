This extension implements an amazing, controllable transparency effect that can be used for ghosts, translucent objects like glass or water, or any other effects (clouds, fog, etc.)! Check out the forum post to see the incredibly cool demo and see how it manages to add transparent/translucent effects with the only 16 colors available! Adds a `Transparency` category to the toolbox.
